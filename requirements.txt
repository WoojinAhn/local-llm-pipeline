# eval/proper-noun-preservation/ compares runs against a committed baseline that is only

# re-measure before trusting a comparison across the bump. See #63, and #42 for the mlx
# core upgrade that is deliberately not taken.
#

#   mlx / mlx-metal  — the compute core. mlx-vlm >=0.6.0 hard-requires mlx>=0.32.0, which

#   safetensors      — weight loading.
#   tokenizers / sentencepiece / transformers — tokenization, and so the token ids the
#                      models actually see.
#   numpy            — array ops in the surrounding pre/post-processing.
#
# This file fixes the packages that matter. It does NOT fix the full dependency closure —
# a fresh resolve still drifts ~45 transitive packages. Use requirements.lock to reproduce
# the exact stack the committed harness baseline was measured on.
